## เรื่องสำคัญที่สุด: ค่าไฟไม่ใช่ 4.18 บาทต่อหน่วย

อัตราบ้านอยู่อาศัยเป็นแบบขั้นบันได หน่วยที่ใช้ชาร์จรถจะไปต่อยอด **บนสุด** ของหน่วยที่บ้านใช้อยู่แล้ว
ถ้าบ้านใช้เดือนละ 250 หน่วยอยู่ก่อนแล้ว หน่วยที่ชาร์จรถทั้งหมดจะโดนขั้น 4.2218 บาทขึ้นไป

ตัวอย่างจริงจากแอป (แบต 67.1 kWh, ประสิทธิภาพ 90%)

| ไฟบ้านเดิม | ชาร์จ | ดึงจากมิเตอร์ | ค่าไฟ | ต้นทุนจริง |
|---|---|---|---|---|
| 0 หน่วย | 20% → 100% | 59.6 kWh | ฿232.66 | 3.90 ฿/kWh |
| 250 หน่วย | 20% → 100% | 59.6 kWh | **฿294.78** | **4.94 ฿/kWh** |
| 500 หน่วย | 20% → 100% | 59.6 kWh | ฿307.54 | 5.16 ฿/kWh |

ค่าเดียวกันทุกอย่าง ต่างกัน 75 บาท เพราะขั้นบันได
ให้ไปตั้งค่า **หน่วยไฟบ้านต่อเดือน ไม่รวมชาร์จรถ** ในหน้าตั้งค่าให้ตรงกับบิลจริง แล้วตัวเลขจะแม่น

## เชื่อม Google Sheet

1. สร้าง Google Sheet ใหม่ 1 ไฟล์
2. เมนู **Extensions → Apps Script** วางโค้ดจาก `google-apps-script.gs` ทับทั้งหมด
3. ถ้าอยากล็อกไม่ให้คนอื่นยิงข้อมูลเข้ามั่ว ให้ตั้ง `var SECRET = 'รหัสอะไรก็ได้';`
4. **Deploy → New deployment → Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec`
6. เปิดแอป → ปุ่มฟันเฟือง → วาง URL (และรหัสถ้าตั้งไว้) → กด **ทดสอบการเชื่อมต่อ**

ชีตชื่อ `ChargeLog` จะถูกสร้างพร้อมหัวตารางให้เอง และระบบกันบันทึกซ้ำด้วย Record ID

> แก้โค้ดใน Apps Script เมื่อไหร่ ต้อง Deploy เวอร์ชันใหม่ทุกครั้ง ไม่งั้น URL เดิมยังรันโค้ดเก่า

## อัปขึ้น GitHub Pages

ต้องขึ้น https ก่อน ไม่งั้น GPS กับการติดตั้งเป็นแอปบนมือถือจะไม่ทำงาน

### วิธีที่ 1 — ผ่านหน้าเว็บ GitHub ไม่ต้องใช้ terminal

1. เปิด https://github.com/new สร้าง repo ชื่อ `b10-charge-log` เลือก **Public** แล้วกด Create
2. ในหน้า repo กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดนี้เข้าไป
   `index.html` `manifest.json` `sw.js` `ev-scene.webp` `ev-scene.jpg` `icon-192.png` `icon-512.png` `icon-maskable-512.png` `apple-touch-icon.png` `.nojekyll`
3. กด **Commit changes**
4. ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **(root)** → **Save**
5. รอ 1–2 นาที เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/b10-charge-log/`

> ไฟล์ `README.md`, `google-apps-script.gs`, `deploy.sh` จะอัปไปด้วยหรือไม่ก็ได้ ไม่มีผลกับการทำงาน
>
> `ev-scene.webp` กับ `ev-scene.jpg` ต้องอัปด้วย ไม่งั้นช่องภาพจะว่าง

### วิธีที่ 2 — ใช้ terminal

```bash
cd โฟลเดอร์ที่มี index.html
./deploy.sh <ชื่อผู้ใช้ GitHub> b10-charge-log
```

หรือพิมพ์เองทีละคำสั่ง

```bash
git init
git add .
git commit -m "B10 Charge Log"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/b10-charge-log.git
git push -u origin main
```

แล้วไปตั้ง Settings → Pages ตามข้อ 4 ข้างบน

### ติดตั้งลงมือถือ

เปิดลิงก์ที่ได้บนมือถือแล้ว

- **iPhone (Safari)** → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
- **Android (Chrome)** → เมนูจุดสามจุด → ติดตั้งแอป

จะได้ไอคอนสายฟ้าบนหน้าจอ เปิดแล้วเต็มจอไม่มีแถบ URL และเปิดดูประวัติได้แม้ไม่มีสัญญาณ

### อัปเดตแอปภายหลัง

อัปโหลด `index.html` ตัวใหม่ทับ แล้วแก้บรรทัดแรกของ `sw.js` จาก `b10-charge-v1` เป็น `v2`
ไม่งั้นเครื่องที่ติดตั้งไว้แล้วจะยังเปิดของเก่าจากแคช

## ทดสอบในเครื่องก่อนอัป

```bash
python3 -m http.server 8080   # แล้วเปิด http://localhost:8080
```

`localhost` ถือว่าปลอดภัย GPS จึงทำงานได้ แต่ถ้าเปิดไฟล์ตรง ๆ ด้วย `file://` ตำแหน่งจะไม่ขึ้น

บริการที่แอปเรียกใช้ ไม่ต้องใช้ API key ทั้งคู่
- สภาพอากาศ: `api.open-meteo.com`
- แปลงพิกัดเป็นชื่อสถานที่: `api.bigdatacloud.net`
